Create a backup

A backup is a compressed file holding every table of the database ({{ database }}): users, declarations, signatures, settings and the audit log. Files are written to {{ backup_dir }} on the server.

Encrypted: every backup is encrypted with AES-256-GCM (key derived from a passphrase with a random salt per file). The passphrase comes from {{ key_source }}{% if key_source == "SECRET_KEY" %}: set BACKUP_PASSPHRASE in .env to use an independent passphrase, and store it in a password manager{% endif %}. Without it a backup cannot be read, so keep it separate from the backups themselves.
